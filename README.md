# Darkloard

Darkloard is a rather simple terminal emulator written in
[C99](https://en.cppreference.com/c/99) using Xlib.

It was developed for my own personal use, so don't expect
extensive support or new features to be added any time soon.

## OS supported

- Linux

## Requirements

- fontconfig
- X11
- Xft

## Build

```sh
./build.sh
```

## Configure

You can configure the terminal emulator by editing `config.h`
(generated by `./build.sh`) and then running `./build.sh` again.
